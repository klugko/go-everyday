# 90 Days of Go 

Welcome to my **90 Days of Go Challenge**.

The goal is simple:
Code in Go every single day for 90 days.

This repository will contain:

* Daily exercises
* Small projects
* Backend experiments
* Algorithms & data structures
* Concurrency practice
* APIs & system programming
* Notes and learnings

## Why?

I want to deeply understand Go and become confident building fast, scalable, production-ready systems with it.

I believe consistency beats intensity.

## Rules

* Code every day
* Push progress daily
* Learn by building
* Keep improving

---

> “Learn deeply. Build daily. Ship consistently.”
